# Team Task Manager

A full-stack task management web application where teams can create projects, assign tasks, and track progress with role-based access.

## Features

- User Authentication (Signup/Login)
- JWT Authentication
- Role-Based Access (Admin/Member)
- Create Projects
- Create Tasks
- Update Task Status
- Delete Tasks
- Dashboard Analytics
- Protected Routes

## Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
